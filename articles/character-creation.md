``` r
library(courtr)
library(magick)

```

Characters can be viewed and edited through the
[`Edit_Figures()`](https://rachelesrogers.github.io/courtr/reference/Edit_Figures.md)
function. This function will open an RShiny app that allows for the
customization of characters. The available character outfits and faces
are shown below.
